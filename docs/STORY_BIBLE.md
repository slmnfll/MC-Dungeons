# Dungeons Story Bible

This is the narrative index for the Dungeons game mode. Detailed stories live in a folder for each Chapter and a separate file for each Season.

## Structure

- One **Chapter** is a complete overarching story.
- One Chapter contains **ten Seasons**, numbered I through X.
- One Season contains **five Adventure Dungeons**.
- Season X contains the Chapter antagonist and concludes the Chapter.
- The next Chapter begins a different story using the same structure.

## Seasonal Progression

- Target Season length: approximately eighteen months.
- Average target for Seasonal Dungeon Level 100: approximately one year.
- Seasonal Dungeon Level resets with each Season.
- Working dungeon unlock levels: **1, 20, 40, 70 and 100**.
- Dungeon unlocks can also require previous dungeon clears and story objectives.
- Adventure, Community, side, dungeon and guild content supports progression between unlocks.
- Previous achievements should be remembered even when seasonal power resets.
